# Academy Hub

Prototipo di studio: un'applicazione interna per l'Academy di un'azienda immaginaria. I dipendenti si iscrivono ai corsi, il responsabile approva, l'Academy conferma i posti; presenze e valutazioni finiscono su una piattaforma dati, dove vengono controllate e trasformate in report.

> Tutti i dati sono sintetici. Il progetto usa solo piani gratuiti: GitHub Free, Databricks Free Edition, strumenti open source in locale.
